# Font licences

The fonts in this directory are self-hosted so the site makes **zero
third-party requests**. All three families are open source, but every one of
them requires its licence to travel with the files, so it is recorded here.

| File | Family | Upstream | Licence |
| --- | --- | --- | --- |
| `Geist-Regular.woff2`, `Geist-Medium.woff2`, `Geist-SemiBold.woff2`, `Geist-Bold.woff2` | Geist | [vercel/geist-font](https://github.com/vercel/geist-font) | SIL Open Font License 1.1 |
| `Newsreader-Regular.woff2`, `Newsreader-Italic.woff2` | Newsreader | [google/fonts](https://github.com/google/fonts/tree/main/ofl/newsreader) | SIL Open Font License 1.1 |
| `DepartureMono-Regular.woff2` | Departure Mono | [rektdeckard/departure-mono](https://github.com/rektdeckard/departure-mono) | SIL Open Font License 1.1 |

Copyright remains with the respective authors. The full text of the SIL Open
Font License 1.1 is at <https://openfontlicense.org/open-font-license-official-text/>.

The OFL permits bundling and redistribution of the font files, including for
commercial use, provided the licence accompanies them and the fonts are not
sold on their own. Nothing here does that.

The `_*.ttf` files that sit alongside these are local build intermediates used
by the favicon and social-card generators. They are gitignored and are not part
of the published site.
